# POS Cafe Software Premium

A comprehensive Point of Sale (POS) system designed for cafes and restaurants with advanced inventory management, analytics, and order processing capabilities.

## Features

- 📱 Responsive design for both mobile and desktop
- 🛒 Order management and tracking
- 💳 Multiple payment methods support
- 🧾 Bill generation and printing
- 📊 Advanced analytics dashboard with visual reports
- 📦 Inventory management and stock alerts
- 👥 Role-based access control (Owner, Employee, Viewer)
- 🌙 Dark/Light theme support

## Tech Stack

- **Frontend**: React 18 with TypeScript
- **Styling**: Tailwind CSS
- **State Management**: Zustand
- **Backend**: Supabase
- **Animations**: Framer Motion
- **Data Visualization**: Recharts
- **Notifications**: React Hot Toast
- **Build Tool**: Vite

## Getting Started

1. Clone the repository
2. Install dependencies:
   ```
   npm install
   ```
3. Copy `.env.example` to `.env` and configure your Supabase credentials
4. Start the development server:
   ```
   npm run dev
   ```
